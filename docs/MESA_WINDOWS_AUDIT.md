# Experimental Mesa for Windows Server 2008 R2 — 2026-10-30

The Server 2008 R2 diagnostic and local pilot include unmodified `opengl32.dll` and `libgallium_wgl.dll` from [mesa-dist-win 26.2.5 MSVC x64](https://github.com/pal1000/mesa-dist-win/releases/tag/26.2.5). The upstream archive SHA-256 is `997123ef4ce8896204ab912d5b54f19372c487ff9835bcefafa2fca23b8953c2`. The DLL hashes are `c8511461ba71a0288750467e3be2f5c1c2bbbceaaf0ab5d8c496b0ba7302daa8` and `700e1fb7b9487d9d1c53752b03aeb040d22f3731b46aa254d88830b6279474de` respectively. The official Mesa commit differs from the 26.2.5 release tag only in the release-notes checksum; the LLVM commit matches the official 23.1.4 tag. The build scripts are pinned to mesa-dist-win commit `f488445397c538b65b25f5db31b8c5569c51a724`; they apply local patches and enable multiple renderer backends. Exact successful patch application and object-level links in the published DLL are not independently established.
