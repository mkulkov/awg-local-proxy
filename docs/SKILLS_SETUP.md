# Проектные навыки и установка

Комплект содержит пять оригинальных instruction-only навыков AWG Local Proxy. В них нет скачанных скриптов, внешних исполняемых плагинов, сетевых запросов и скрытых dependencies.

Установщик располагается в корне распакованного архива. Из этой папки:

```powershell
.\Install-ProjectSkills.ps1 -TargetPath 'C:\dev\GO\AwgLocalProxy'
```

Для предварительного просмотра: добавь `-WhatIf`. Если PowerShell блокирует запуск, не меняй глобальную execution policy: открой файлы в локальном Codex и поручай ему прочитать и выполнить проверенный установщик в рамках действующей политики.

Установка создаёт project-local `.agents/skills`, копирует инструкцию и документацию и добавляет в AGENTS.md только небольшой управляемый блок с указанием прочитать AGENTS.AWG.md. Существующие правила сохраняются. При конфликте файла нет молчаливой перезаписи; явный `-Force` создаёт резервную копию заменяемых файлов в LocalAppData. Не используй Force без просмотра различий.

Установщик работает без сети, не вызывает GitHub, не устанавливает Go/Fyne, не меняет config.toml и не требует администратора. Он проверяет хеши payload по manifest; это контроль целостности комплекта, а не цифровая подпись его источника.

После установки открой каталог проекта в Codex и проверь наличие:

- `$awg-go-netstack`
- `$awg-windows-fyne`
- `$awg-security-tests`
- `$awg-github-upstream`
- `$awg-release-ci`

При необходимости обнови список skills или начни новую сессию. Фактическую видимость и срабатывание проверь короткими задачами, не объявляй по одному факту копирования файлов.

Проверки контекстного подключения: задача про сетевой dial -> awg-go-netstack, без UI-навыка; задача про tray -> awg-windows-fyne; задача про fork -> awg-github-upstream; задача про утечки -> awg-security-tests; задача про сборку релиза -> awg-release-ci.

Официальные универсальные навыки openai/skills не входят в этот комплект и не устанавливаются этим скриптом. Существующие глобальные навыки пользователя не обследованы с локального диска и не изменены.

В среде подготовки комплекта проверены структура, frontmatter, manifest и целостность ZIP. На компьютере пользователя установка не выполнялась; PowerShell/Windows smoke-тест установщика остаётся задачей локального Codex.
