# AWG Local Proxy — локальная сборка для Windows

1. Оставьте `AwgLocalProxy.exe` и `awg-proxy-core.exe` в одной папке и запустите `AwgLocalProxy.exe` от обычного пользователя.
2. На вкладке «Профили» импортируйте клиентский `.conf` со своего компьютера. Профиль шифруется Windows DPAPI для текущего пользователя; исходный файл не удаляется. В чат конфигурацию и ключи отправлять не нужно.
3. На вкладке «Подключение» выберите профиль и введите свой HTTP(S)-адрес для проверки через туннель. При подключении на него будет отправлен запрос. Укажите адрес, которому доверяете и который доступен через VPN; приложение не выбирает сторонний сервис автоматически.
4. Нажмите «Подключить». После успешных handshake и проверки настройте нужное приложение на SOCKS5 `127.0.0.1:1080`; включите в нём разрешение DNS через proxy, если такая настройка есть. HTTP proxy `127.0.0.1:8080` включается отдельным флажком. Порты можно изменить на вкладке «Настройки» до подключения. Для автоподключения сохраняются выбранные значения; иначе после перезапуска используются значения по умолчанию.
5. Для проверки позднее используйте кнопку «Проверить туннель ещё раз»; для завершения соединения — «Отключить». Закрытие окна скрывает его в трей, пункт трея «Завершить» завершает программу.

В настройках можно отдельно включить запуск интерфейса при входе в Windows и сохранить автоподключение к выбранному профилю. Оба пункта по умолчанию выключены. Если выбрано автоподключение, при запуске будет использоваться сохранённый вами адрес проверки. Включение повторных попыток также отдельно; кнопка «Отключить» отменяет текущие повторы, а чтобы отменить автоподключение при следующем запуске, снимите соответствующий флажок и сохраните настройки.

Приложение не перенаправляет весь трафик Windows. Программы могут игнорировать proxy; UDP, QUIC, WebRTC и DNS, разрешённый самим приложением до передачи адреса прокси, могут идти вне туннеля. Loopback доступен и другим локальным процессам. Перезапуск или замена только одного EXE может привести к ошибке проверки хеша: используйте пару из одной сборки.

Импорт поддерживает только ограниченный набор полей `.conf` и одного Peer; `.vpn` и неизвестные/небезопасные поля отклоняются. Совместимость с конкретным сервером не подтверждена. Эта сборка не подписана; её хеши находятся в `SHA256SUMS`. Условия сторонних компонентов — в `THIRD_PARTY_NOTICES.md` и `third_party/licenses/`.
