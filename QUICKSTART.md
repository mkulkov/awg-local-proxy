# AWG Local Proxy — локальная сборка для Windows

Требуется 64-разрядная Windows 10 или новее (Windows Server 2016 или новее). Текущая сборка не поддерживает 32-разрядную Windows и более старые версии.

1. Оставьте `AwgLocalProxy.exe` и `awg-proxy-core.exe` в одной папке и запустите `AwgLocalProxy.exe` от обычного пользователя.
2. На вкладке «Профили» импортируйте клиентский `.conf` или `.vpn` со своего компьютера. Профиль шифруется Windows DPAPI для текущего пользователя; исходный файл не удаляется. В чат конфигурацию и ключи отправлять не нужно.
3. На вкладке «Подключение» выберите профиль и введите свой HTTP(S)-адрес для проверки через туннель. При подключении на него будет отправлен запрос. Укажите адрес, которому доверяете и который доступен через VPN; приложение не выбирает сторонний сервис автоматически.
4. Нажмите «Подключить». После успешных handshake и проверки настройте нужное приложение на SOCKS5 `127.0.0.1:1080`; включите в нём разрешение DNS через proxy, если такая настройка есть. HTTP proxy `127.0.0.1:8080` включается отдельным флажком. Порты можно изменить на вкладке «Настройки» до подключения. Для автоподключения сохраняются выбранные значения; иначе после перезапуска используются значения по умолчанию.
5. Для проверки позднее используйте кнопку «Проверить туннель ещё раз»; для завершения соединения — «Отключить». Закрытие окна скрывает его в трей, пункт трея «Завершить» завершает программу.

В настройках можно отдельно включить запуск интерфейса при входе в Windows и сохранить автоподключение к выбранному профилю. Оба пункта по умолчанию выключены. Если выбрано автоподключение, при запуске будет использоваться сохранённый вами адрес проверки. Включение повторных попыток также отдельно; при их включении после события пробуждения выполняется ограниченное восстановление ранее активного соединения; кнопка «Отключить» отменяет текущие повторы, а чтобы отменить автоподключение при следующем запуске, снимите соответствующий флажок и сохраните настройки.

Если в профиле указан домен VPN-сервера, при подключении он разрешается системным DNS до создания туннеля. Для исключения этого запроса используйте числовой IP endpoint в своём профиле. Импорт сам по себе DNS не запрашивает.

Приложение не перенаправляет весь трафик Windows. Программы могут игнорировать proxy; UDP, QUIC, WebRTC и DNS, разрешённый самим приложением до передачи адреса прокси, могут идти вне туннеля. Loopback доступен и другим локальным процессам. Перезапуск или замена только одного EXE может привести к ошибке проверки хеша: используйте пару из одной сборки.

Импорт поддерживает один Peer и ограниченный набор полей AWG. Из `.vpn` извлекается только клиентский профиль; административные данные не сохраняются. Подписки, неоднозначные экспорты и неизвестные или небезопасные поля отклоняются. Совместимость с конкретным сервером не подтверждена. Эта сборка не подписана; её хеши находятся в `SHA256SUMS`.
