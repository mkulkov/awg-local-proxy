# AWG Local Proxy — демонстрационная оболочка

Независимое Windows-приложение на Go + стабильной Fyne v2.8.2. **Демонстрационный режим — VPN не подключён.** Эта версия не открывает SOCKS5/HTTP-порты, не разрешает адреса назначения и не передаёт трафик. Кнопка запускает демонстрацию обмена с отдельным MockCore-процессом.

Продукт: [mkulkov/awg-local-proxy](https://github.com/mkulkov/awg-local-proxy). Сетевой компонент находится отдельно: [mkulkov/amnezia-proxy](https://github.com/mkulkov/amnezia-proxy). Его исходники не включены, не загружаются при запуске и не собираются продуктом. Интеграция заблокирована отсутствием явной разрешающей лицензии; см. [лицензионный отчёт](docs/LICENSE_AUDIT.md) и [core.lock.json](core.lock.json). Лицензия собственного продукта пока не утверждена; лицензии зависимостей не означают лицензирование всего продукта.

Реализованы окно с шестью разделами, трей, скрытие окна, демонстрационный дочерний процесс, ограниченный stdio IPC, профильные метаданные и DPAPI CurrentUser. Приложение не требует драйвера/службы и не меняет маршруты, DNS, системный proxy, переменные proxy или firewall. В рабочем будущем режиме только приложения с явной поддержкой SOCKS5/HTTP смогут использовать прокси. Выбор EXE не будет перехватывать трафик.

Импорт `.conf` сохраняет ограниченный клиентский профиль в DPAPI без подключения и без передачи MockCore. Принимается один Peer, числовой IP Endpoint, числовые DNS, известные поля и ограниченный размер 64 КиБ. Комментарии опускаются; hooks, дублированные/неизвестные поля, inline comments, административные экспорты, `.vpn`, I1–I5 и диапазоны H отклоняются. J/S/H допускаются только в консервативной десятичной числовой форме. Полная совместимость/семантика AWG не проверены. Исходный файл остаётся на месте. Подробности и незавершённые функции — [IMPLEMENTATION.md](docs/IMPLEMENTATION.md).

Хранилище: `%LOCALAPPDATA%/AwgLocalProxy/profiles`. Не отправляйте конфигурации, ключи, логи или захваты трафика в GitHub и чат. DPAPI не защищает от программ с правами того же пользователя.

Для разработки нужны Go (минимум 1.25), Windows C toolchain для Fyne/CGO и OpenGL. Проверенная в этой рабочей среде версия Go — 1.27.3. После настройки Go/компилятора в текущем процессе PowerShell:

```powershell
go mod download
go test -tags ci ./...
go vet -tags ci ./...
go build -trimpath -ldflags="-H=windowsgui" -o dist/AwgLocalProxy-demo.exe ./cmd/awg-local-proxy
go build -trimpath -o dist/awg-mock-core.exe ./cmd/awg-mock-core
```

`-tags ci` выполняет headless-проверку; она не заменяет ручные проверки окна, DPI, tray, accessibility, второго запуска и завершения дочернего процесса при аварии GUI. Отдельный mock executable — фикстура протокола; GUI запускает собственный executable как отдельный `--mock-core` процесс. [Протокол](contracts/stdio-v1.md) не является существующим интерфейсом upstream.

Реального VPN/core в этой версии нет. Подключение к серверу пользователя, AWG handshake, DNS через туннель и запросы SOCKS5/HTTP не проверялись. Неподписанный демонстрационный EXE нельзя считать готовым VPN-клиентом.
