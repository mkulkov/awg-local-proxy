# AWG Local Proxy

**Текущая сборка рассчитана на 64-разрядную Windows 10 или новее (Windows Server 2016 или новее).** На 32-разрядной Windows и в более старых версиях Windows она не поддерживается.

Windows-приложение на Go и Fyne для приложений, которые самостоятельно настроены на локальный SOCKS5 или HTTP proxy. Системные маршруты, DNS, proxy, firewall и службы не настраиваются; перехват трафика по EXE не выполняется.

Используется независимый отдельный [core](https://github.com/mkulkov/awg-local-proxy-core) на основе официального AmneziaWG: [выбор и лицензии](docs/CORE_SELECTION.md). Код `synacker/amnezia-proxy` не включён: [лицензионный аудит](docs/LICENSE_AUDIT.md). Базовая сборка без закреплённого core остаётся сетевой демонстрацией.

Автозапуск интерфейса, автоподключение и ограниченное повторное подключение — отдельные настройки, по умолчанию выключенные. Автоподключение и повторные попытки используют только явно выбранные профиль и адрес проверки; настройки зашифрованы DPAPI. Автозапуск добавляет запись только в HKCU Run и включается пользователем вручную.

Для подключения в интерфейсе нужно выбрать импортированный клиентский `.conf` или `.vpn` и самостоятельно указать HTTP(S) адрес проверки, доступный через туннель. Приложение обращается к нему через туннель при подключении и по кнопке повторной проверки. Статус означает результат последней проверки, а не непрерывный мониторинг. SOCKS5 работает на `127.0.0.1:1080`; HTTP proxy `127.0.0.1:8080` включается отдельно. Порты можно изменить в настройках до подключения; для автоподключения сохраняются выбранные значения, иначе после перезапуска используются значения по умолчанию. Другие локальные процессы могут использовать эти адреса. UDP/QUIC и приложения, игнорирующие proxy, не защищаются.

Профили шифруются Windows DPAPI CurrentUser, исходный файл не удаляется. Не отправляйте конфигурации или ключи в чат, GitHub и логи. DPAPI не защищает от программ с теми же правами пользователя. Клиентский профиль ограничен одним Peer, 8 КиБ и проверяемым подмножеством параметров AWG; endpoint может быть числовым IP или ASCII-именем сервера. Имя VPN-сервера при подключении разрешается системным DNS; остальные DNS-запросы самого core проходят через туннель. Поддерживаются `.conf` и локальные `.vpn` с одним клиентским профилем AWG; дополнительные административные данные из экспорта не сохраняются. Подписки, неоднозначные экспорты, неизвестные поля и hook-команды отклоняются. См. [реализацию](docs/IMPLEMENTATION.md).

Локальная разработческая сборка двух отдельных модулей:

```powershell
.\scripts\build-local.ps1 -CoreSource 'C:\path\to\AwgLocalProxyCore' -IncludeSBOM
```

Нужны Go 1.25+, C-компилятор для Fyne и корректный PATH текущей сессии. Скрипт записывает каждую сборку в новый каталог `dist/local-*`, встраивает в GUI SHA-256 соседнего core и формирует `SHA256SUMS`. Хеш обнаруживает несовпадение файлов, но не удостоверяет происхождение неподписанного билда. Дистрибутив и релиз требуют проверки лицензий зависимостей и notices; локальная сборка не является опубликованным релизом.

Текущее покрытие и реальные проверки — в [TEST_RESULTS.md](docs/TEST_RESULTS.md). Совместимость с сервером пользователя не подтверждена. Никогда не считайте открытый локальный порт или запуск устройства доказательством работающего VPN.
